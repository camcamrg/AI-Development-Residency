# Project Instructions

## Skills — always apply
Before starting any task, check `.claude/skills/` and apply every relevant skill. Do not skip one that applies.

- secret-management — handling passwords, API keys, tokens, or credentials
- accessible-design — building or reviewing any UI (always on)
- ux-design — building or reviewing any interface or flow (always on)
- write-tests — writing, running, or checking test coverage
- open-pull-request — opening a PR or putting code up for review
